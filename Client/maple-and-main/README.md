# Maple & Main Bakery (the example brand)

**This bakery is made up.** The town, the people, the numbers and the customers do not exist.
It ships with Social Media Factory so you can see a finished brand, try every tool before you
have onboarded your own, and so the automated tests have something real-shaped to run against.

Delete this folder whenever you like. Nothing depends on it except the demos and the tests.

To build your own brand, ask Claude: "onboard my brand".
