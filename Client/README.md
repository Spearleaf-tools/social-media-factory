# Client/ — your brands live here

Each folder in here is one brand. Your brands **stay on your computer**: this folder is ignored by
git on purpose, so if you ever copy or publish this project, your brand, your drafts and your
posting history do not go with it.

`maple-and-main/` is a made-up bakery that ships with the Social Media Factory so you can try every tool
before you have set up your own. Delete it whenever you like.

To add your own brand, ask Claude: **"onboard my brand"**.
