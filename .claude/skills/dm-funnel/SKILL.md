# DM funnel

The craft is in `playbooks/dm-funnel.md`. Read it before the first build.

## How to run this conversation

- **You do the work. They never see a setting name.** Say "the part that answers comments is
  ready" not "workflow published".
- **One question at a time**, with a default.
- **Nothing is built before they approve every message.** This is the hard stop.
- **Never invent.** The bonus and the three choices must be real things the brand already has,
  with real links. If something is missing, ask for it.
- **Always name the brand.** One brand's messages must never reach another brand's account.
- **Say the cost before any sign-up** (see the playbook's "What it needs").

## Steps

1. **What do you have?** Which Instagram account, which tool (GoHighLevel or ManyChat; if neither,
   explain the cost and stop until they choose), and what they'd give away.
2. **Their ladder.** One thing to buy, one free sample, one big step (call, application,
   consultation). Get the link for each.
3. **Write the six messages** in their voice from `Brand/voice-samples.md`, using the playbook's
   shape. Quick replies 20 characters or fewer. Show it all on one page. Wait for a yes.
4. **Build** following the playbook's build shape (GoHighLevel), or the same flow in ManyChat.
   Changes on their live account: tell them exactly what goes live, and get a yes first.
5. **Test with them.** They comment the word from a different account that hasn't commented on
   that post. Walk each message together.
6. **Save** the approved messages and what was built in the brand's `Studio/dm-funnel/` folder.
7. **Every new post with a keyword:** add it to the comment automation right after it goes live.
